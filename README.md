# Информационная система «Учебные курсы»

Настольное приложение для организации дистанционного обучения школьников:
WPF, C#, .NET Framework 4.7.2, Microsoft SQL Server.

## Возможности

* Регистрация и авторизация пользователей с разграничением прав доступа
  (администратор, учитель, ученик).
* Ведение справочников: пользователи, учебные группы, дисциплины, преподаватели, курсы.
* Создание курсов и заданий, назначение сроков сдачи и максимального балла.
* Выполнение заданий учениками и их проверка преподавателем с выставлением оценок
  и комментариев.
* Формирование ведомости успеваемости с выгрузкой в текстовый файл.
* Импорт пользователей и курсов из xml-файлов.
* Хранение паролей в виде PBKDF2-хешей (PBKDF2-HMAC-SHA256, 100 000 итераций).

## База данных

Схема состоит из десяти связанных таблиц с префиксом `23_09`:
`Polzovateli`, `Gruppy`, `Ucheniki`, `Prepodavateli`, `Discipliny`, `Kursy`,
`Zadaniya`, `ZapisNaKursy`, `Vypolneniya`, `Ocenki`.
Все связи заданы внешними ключами, значения ограничены проверками `CHECK`.

База данных развёрнута на сервере Microsoft SQL Server; приложение подключается
к ней по параметрам из файла конфигурации (см. следующий раздел).

## Сборка и запуск

```powershell
# Visual Studio 2019: открыть WpfApp1.sln и собрать
# либо из командной строки:
msbuild WpfApp1.csproj /t:Rebuild /p:Configuration=Release
```

Готовый исполняемый файл: `Матулов УП03\WpfApp1\WpfApp1\bin\Debug\WpfApp1.exe`
(приложение 32-разрядное, требуется .NET Framework 4.7.2 и доступ к серверу базы данных).

## Параметры подключения

В репозитории файл `App.config` содержит обезличенную схему подключения —
пароль заменён на `CHANGE_ME`, чтобы действующие учётные данные сервера
не попадали в открытый репозиторий.

Реальные параметры задаются одним из двух способов:

1. файл `App.config.local` рядом с исполняемым файлом (не входит в репозиторий);
2. непосредственно в разделе `connectionStrings` файла `WpfApp1.exe.config`.

Формат `App.config.local`:

```xml
<configuration>
  <connectionStrings>
    <add name="DefaultConnection"
         connectionString="Server=<сервер>,<порт>;Database=user87_db;User Id=<пользователь>;Password=<пароль>;"
         providerName="System.Data.SqlClient" />
  </connectionStrings>
</configuration>
```

При отсутствии параметров приложение выводит понятное сообщение об ошибке.
